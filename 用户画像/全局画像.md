# 全局画像提示词

## 概述
全局画像是对用户的基本信息、个人特征、学习习惯、行为偏好等进行的综合画像，是跨所有学习方向的基础用户模型。

---

## 二、学习习惯维度

### 1. 学习时间习惯
**学习时段偏好**：
- 早晨型（6:00-10:00）
- 上午型（10:00-14:00）
- 下午型（14:00-18:00）
- 晚上型（18:00-24:00）
- 深夜型（0:00-6:00）

**学习频率**：
- 每天学习
- 工作日学习
- 周末学习
- 间歇性学习

**单次专注时长**：
- 短（<30分钟）
- 中（30-60分钟）
- 长（60-90分钟）
- 超长（>90分钟）

**学习周期规律**：
- 持续稳定型
- 突击冲刺型
- 循序渐进型
- 劳逸结合型

### 2. 学习环境偏好
**环境类型**：
- 安静环境（图书馆/自习室）
- 有背景音乐
- 咖啡店/公共空间
- 家里/宿舍
- 户外学习

**设备偏好**：
- 电脑为主
- 平板为主
- 手机为主
- 多设备切换

### 3. 学习方法偏好
**学习策略**：
- 系统学习型（从基础到深入）
- 问题驱动型（遇到问题再学）
- 实践导向型（边做边学）
- 理论研究型（深入原理）
- 混合策略型

**记笔记习惯**：
- 详细笔记型
- 思维导图型
- 要点记录型
- 电子笔记
- 纸质笔记
- 不记笔记

**复习习惯**：
- 定期复习
- 考前复习
- 按需复习
- 很少复习

## 六、更新触发条件

1. **首次注册/登录**：通过对话收集基本信息
2. **学习行为积累**：根据行为数据更新习惯维度
3. **主动更新**：用户手动修改个人信息
4. **定期评估**：每2周重新评估学习习惯是否变化
5. **重要节点**：学期开始/结束、实习前后等

## 七、AI提示词模板

```
你是全局画像分析智能体，请基于以下信息构建/更新用户的全局画像：

【用户输入】
{用户的对话内容、问卷反馈或行为数据}

【当前画像数据】
{当前的全局画像JSON}

请分析并：
1. 提取用户的基本信息
2. 分析学习习惯特征
3. 识别行为偏好模式
4. 更新个人特质描述
5. 输出更新后的完整画像JSON

要求：
- 信息客观准确，基于实际数据
- 学习习惯从行为中推断，不主观臆断
- 偏好类型从给定选项中选择最匹配的
- 保持数据结构一致性
```

## 八、应用场景

1. **个性化推荐**：基于习惯和偏好推荐适配的学习资源
2. **学习计划制定**：根据时间习惯安排合理的学习计划
3. **学习提醒**：在偏好的学习时段进行学习提醒
4. **界面适配**：根据设备和交互偏好调整界面展示
5. **学习策略建议**：结合个人特质提供学习方法建议
