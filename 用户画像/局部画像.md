## 二、局部画像核心维度（单个学习方向）

### 1. 知识基础维度
**定义**：用户在该学习方向上的现有知识储备、技能水平和认知起点。

**核心要素**：
- 整体水平评级（入门/初级/中级/高级/专家）
- 已掌握的技能点清单
- 知识掌握程度分布
- 前置知识掌握情况
- 相关领域知识关联

**数据来源**：
- 技能树节点状态
- 测验成绩
- 项目/作品记录
- 自我评估

---

### 2. 学习进度维度
**定义**：用户在该学习方向上的学习进展、完成度和时间投入。

**核心要素**：
- 已完成的学习节点数
- 总体完成度百分比
- 累计学习时长
- 学习开始和持续时间
- 当前学习阶段
- 学习速度（节点/周）

**数据来源**：
- 学习记录
- 节点完成时间
- 时长统计
- 进度追踪

---

### 3. 能力特点维度
**定义**：用户在该学习方向上展现出的能力优势、劣势和特点。

**核心要素**：
- 优势能力领域
- 劣势/薄弱环节
- 擅长的技术栈/工具
- 不擅长的技术点
- 能力成长曲线

**数据来源**：
- 答题表现分析
- 项目完成质量
- 技能应用情况
- 错题分析

---

### 4. 学习目标维度
**定义**：用户在该学习方向上的短期、中期和长期目标。

**短期目标（1-3个月）**：
- 掌握特定技能点
- 完成某个项目
- 通过某项认证
- 达到特定水平

## 四、多学习方向结构

一个用户可以同时有多个学习方向的局部画像：

```json
{
  "user_id": "用户ID",
  "directions": {
    "frontend": {
      "status": "active",
      "priority": 1,
      "profile": {...}
    },
    "algorithm": {
      "status": "active",
      "priority": 2,
      "profile": {...}
    },
    "backend": {
      "status": "pending",
      "priority": 3,
      "profile": {...}
    }
  }
}
```

**方向状态**：
- **active** - 当前正在学习
- **pending** - 计划学习
- **paused** - 暂停学习
- **completed** - 已完成（达到目标）
- **archived** - 已归档

## 五、更新触发条件

### 单个学习方向更新
1. **开始学习新方向**：初始化该方向的局部画像
2. **完成技能树节点**：更新知识基础和学习进度
3. **完成测验/项目**：更新能力特点和成果记录
4. **调整学习目标**：更新学习目标维度
5. **定期复盘**：每2周评估该方向的整体情况

### 多方向管理
1. **添加新方向**：用户新增学习方向时创建
2. **切换主要方向**：调整优先级和状态
3. **暂停/恢复方向**：学习状态变更时更新
4. **完成方向目标**：标记为completed状态

## 七、与全局画像的协同

### 全局画像 → 局部画像
- 学习习惯 → 推荐该方向的学习计划安排
- 行为偏好 → 推荐该方向的资源类型
- 个人特质 → 优化该方向的学习策略

### 局部画像 → 全局画像
- 各方向进度 → 整体学习成就感
- 能力特点 → 综合能力图谱
- 成果记录 → 个人成就体系
