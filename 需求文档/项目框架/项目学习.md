vue前端学习
<template>
  <!-- 页面结构（HTML） -->
  <div>{{ message }}</div>
</template>



<script setup lang="ts">
// 页面逻辑（JavaScript/TypeScript）
import { ref } from 'vue'
const message = ref('Hello!')  // 响应式变量
</script>

ref() 函数用于创建响应式变量，可以在模板中直接使用。
reactive() 函数用于创建响应式对象，可以在模板中直接使用。


v-model 指令用于将表单元素的值与响应式变量绑定，实现数据的双向绑定。
v-model 可以与 v-model.number 等修饰符结合使用，实现数值类型的双向绑定。
v-model.trim 可以自动移除输入框的首尾空格。
v-model.lazy 可以将数据绑定延迟到输入框失去焦点时。
v-if 指令用于根据响应式变量的值来条件渲染元素。
v-for 指令用于遍历数组或对象，将每个元素渲染为一个列表项。
router.push() 方法用于导航到指定路由。

</style>

@PostMapping 处理 POST 请求（新增） 
@RequestBody 接收前端传来的 JSON 数据
